# Restore the documentation TOC shared range

Bounded user-directed #843 follow-up. This is implementation context, not a new normative guarantee.

- Original animation baseline: `411c354cfbf76e9da34eafa90f1c8a7b973d043c` (`17165ea1ce^`), whose TOC computes a shared first/last visible-link rectangle and moves/resizes it with a 300ms transition. `506b8d58ec` removed that feedback.
- Development starts from merged #777 main `b27e93a2f3b0dfae52dfa7f0473cca3f19d0d56f`, with published #816 `a048b687c4f24491f6d1cc1c5019bb2467c00d7a` as an explicit read-only dependency. #816 owns the unique-current/in-view separation and desktop density. This follow-up does not modify its branch.
- `StarlightTOC` remains the application geometry owner. Its existing rAF reads headings plus at most three range rectangles before writing native current/in-view facts and the single passive mount. Identical geometry does not write styles again. ResizeObserver, font loading, hash/history restoration and viewport changes invalidate the same rAF; detach cancels work and hides the range.
- The existing static-documentation WC bridge mounts one actual public Shadcn/Brutalist Surface in that aria-hidden mount, sharing the existing root theme sampling and teardown. The public Base-derived Surface owns muted paint/radius; app CSS only owns placement, stacking and transform/size transitions. No new prototype, API, selector/selection state machine, package surface or lifecycle promotion is introduced.
- Native anchors, their labels and unique current remain intact. SSR without JavaScript retains its links and leaves the empty passive mount hidden. Reduced-motion removes the geometry transition.
- A focused geometry red case fails on the unchanged #816 dependency because no transform is written. Restored tests exercise downward/upward range movement, unique current, one pending frame for twenty scroll invalidations, read-before-write ordering, unchanged-style suppression, reflow without scroll, hash invalidation, stale-frame rejection and reconnection. A real-atom test covers one public family Surface, inherited style tokens, theme batch reuse, family replacement and disposal. Injected DOM rectangles are explicitly host-unit evidence, not browser animation proof.
- Browser animation, matched baseline/candidate captures, reduced-motion/no-JS browser coverage and elapsed performance remain separate required evidence. Unit counts do not establish full performance parity. Preserve failed environment launches and any failed observations in the evidence report rather than replacing them with green checks.
