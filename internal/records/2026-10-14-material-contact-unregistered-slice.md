## Scope and status

PR #887 candidate baseline: `618c7f75ac8b74780237bf50363296e58016bd96`. This slice adds four portable Core types, the draft `C/M/HC/T-MATERIAL-CONTACT-0001` entities and a private, unregistered module. It is association middleware with fake-host evidence. No production consumer, author hook, Runtime assembly, Compiler/IR, input recognizer, material sink or backdrop transport is changed.

The first consumers represented by fixtures are self, Switch Root to eventless Thumb and Slider Track to its existing input Thumb. General direct manipulation for every style remains the Base/Input owner's responsibility. Material only observes an already-authorized input stream; it does not own capture, recognition, activation, values, focus or accessibility.

## Implemented boundary

- Setup-only bilateral declarations resolve exact Anatomy family/domain/key/roles. Missing or duplicate endpoints never select the first matching part.
- Both endpoints need current physical view identities and epochs, a common document and the same trusted host-capability object. A receiving material slot alone does not authorize an input source.
- The live host registry must recognize the immutable input read lease. Malformed, mismatched or mutated registrations remain quarantined even if repaired in place.
- Contact snapshots remain host-private and finite. Pending, active, released and cancelled phases neither request nor synthesize input behavior.
- Initial subscription is a readiness fence, not replay. Revision high-water marks and retired sessions survive paint-only reattachment for the reader's lifetime.
- Deferred work checks the current binding. Delivery tokens and generation checks prevent reentrant reads, clear, disposal or replacement from reviving old work.

## Independent review corrections

Independent falsification found and reproduced four classes of defects in the first implementation: a clear callback could invert sample order; paint-only remount forgot retired sessions/revisions; repaired registrations regained reader authority, including initially malformed registrations; and a final host read could dispose the receiver yet still create a paint lease. The corrected slice uses input-lifetime state, permanent reader quarantine, delivery freshness fences and a final pre-connect generation/liveness check. Reproductions and additional host-identity, snapshot-isolation and throwing-cleanup controls are retained in the module's normal tests.
