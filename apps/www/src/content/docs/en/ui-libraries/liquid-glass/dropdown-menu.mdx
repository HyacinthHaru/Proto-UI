## Grouped action composition (draft)

Group and Label provide a live accessible naming relationship; Separator and Shortcut are real passive parts. Shortcut only displays a hint and does not register a global binding. Decorative parts do not enter the action collection or add a press owner. The demo uses a 160px menu, grouped account/resources actions and a disabled API action. The real Invite users submenu is a separately pending protocol slice, not a simulated demo box. Checkbox/radio variants and complete native/GPUI, compiler, packed, visual and independent acceptance remain open.

## Explicit Trigger material (draft)

Trigger now declares the shared `liquid-glass` intent. Its existing Dropdown pressed state selects rest/pressed deformation; rounded geometry and the complete opaque fallback come from final style. Hover, focus-visible, disabled and menu activation remain owned by Base. Content keeps its existing open-state material intent; this change does not add a second command owner or a demo-only effect.

The existing shared Web material provider can realize the intent only with an admitted in-app canvas source, geometry and preferences. Missing capability, unsafe contrast or unavailable source retains the opaque fallback. A portaled menu may lack an admitted source even when its Trigger is enhanced. This is not native blur or an Apple-native parity claim. The source recipe and isolated intent tests are implementation evidence only: source-bound WC/React/Vue/Vue 2 light/dark screenshots, actual interaction paint, GPUI and independent visual acceptance remain pending.

The public preview also includes a separately owned disabled Trigger; its immutable authored disabled prop is exercised without test-only DOM mutation.
