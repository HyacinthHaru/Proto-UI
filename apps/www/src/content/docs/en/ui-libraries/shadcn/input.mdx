This entry shows Proto UI's current Shadcn-style projection of Base Input. The compatibility reference is the v4 new-york Input at [`shadcn-ui/ui` revision `f31ed81983653919dd4fe77aee4b4859f610f1dc`](https://github.com/shadcn-ui/ui/blob/f31ed81983653919dd4fe77aee4b4859f610f1dc/apps/v4/registry/new-york-v4/ui/input.tsx). This is an unofficial Proto UI implementation, not an upstream package or endorsement.

Base Input owns the single-line text value, controlled/uncontrolled behavior, normalized editing and IME events, native text properties, textbox naming and description, disabled/read-only state, and focus/blur. The Shadcn layer consumes that protocol and adds a bounded field surface, focus-visible ring, disabled treatment, and dark-scheme background. Exactly one host-owned `input[type="text"]` is rendered.

This is a verified visual subset rather than exact upstream parity. The projection matches upstream text-selection colors with the narrowly allowlisted static `selection:bg-primary selection:text-primary-foreground` tokens. Other style variants such as upstream `placeholder:*` and responsive `md:*` remain unsupported. Upstream does not set a custom text cursor or caret color, so those remain native browser behavior here as well. Base Input has no invalid state, and this projection exposes neither arbitrary `type`, caller `className`, nor `data-slot`. It adds no form/validation workflow, selection API, or second editor.
