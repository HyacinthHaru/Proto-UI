## Trigger appearance

The default `appearance="flat"` keeps the 5px-rounded, 2px black frame, main fill and paired ink shown above. `appearance="elevated"` remains an opt-in Proto UI extension: a 4px right/down hard shadow at rest, with the same 4px hover/press displacement that clears the shadow.

`appearance="ghost"` is a separate opt-in Proto UI extension. Its resting border and fill are transparent, with theme-dependent foreground and no hard shadow. Hover/press use the neutral surface without movement; the hard keyboard focus ring remains visible in both themes. Main-fill black ink never leaks into the transparent dark appearance.

Set `appearance` on `brutalist-select-trigger`, not Root or Content. Omitting or removing it restores `flat`, even during interaction. Size, chevron, Base selection, keyboard navigation, disabled behavior and flat Content are unchanged. Form fields keep the default; consumers choose the public input rather than overriding family paint with CSS.
