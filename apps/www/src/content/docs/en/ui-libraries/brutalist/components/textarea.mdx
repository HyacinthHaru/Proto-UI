Brutalist Textarea preserves Base multiline value, change, disabled, focus, and rows semantics while adding a square paper editor surface and hard shadow.

Compose it with Field for labels and errors, or Composer for submit lifecycle and actions. Textarea owns neither contract.

- Mono text, vertical resize, and an explicit minimum height.
- Shared Brutalist focus-visible and disabled feedback.
- No radius, gradient, glass, or soft inset glow.
