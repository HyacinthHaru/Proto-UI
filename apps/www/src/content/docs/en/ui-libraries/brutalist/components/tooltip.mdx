This slice is a static five-part Tooltip shell: Base defines Root, Trigger, Portal, Content, and Arrow anatomy without open state, hover/focus routing, delay, escape handling, presence, positioning, or portal behavior. Brutalist adds visual feedback only to Content and Arrow.

The preview mounts Content deliberately to show the visual projection. It is not an interactive Tooltip yet; behavior belongs to the separate Base follow-up PR #342. A future Tooltip may supplement an accessible name, but must not replace one.
