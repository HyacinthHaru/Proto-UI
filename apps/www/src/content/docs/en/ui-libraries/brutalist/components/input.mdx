Brutalist Input preserves Base Input value, change, disabled, and focus semantics while projecting a square paper field with an ink frame and hard shadow.

Use Input for conversation search, titles, filters, and compact form fields. Compose Field or InputGroup for labels, descriptions, validation messages, and attached actions; Input does not duplicate those contracts.

- `2px` ink border, mono text, paper fill, hard offset shadow.
- Shared Brutalist focus-visible and disabled feedback.
- No radius, gradient, glass, or soft inset glow.
- Explicit anatomy composition works without presets.
