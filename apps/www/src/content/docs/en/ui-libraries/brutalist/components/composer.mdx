Brutalist Composer is a message input row with send action.

- **Root**: paper surface row with hard shadow and ink border
- **Input**: canvas textarea with square border
- **Actions**: action container
- **SendButton**: canary square button with press effect

All parts share a `disabled` state. Disabling the root propagates to children.
