Base Scroll Area now publishes viewport metrics, exact orientation-aware Thumb ratios, and clamped Thumb drag scroll requests while native overflow remains host-owned. The Brutalist family adds square paper surfaces and high-contrast Lavender/ink controls.

This private shell does not yet project the continuous ratios into proportional Thumb size or offset; that needs an adapter-neutral continuous-style projection. Use the current preview for native scrolling and protocol evidence, and give Root an explicit size in surrounding layout.
