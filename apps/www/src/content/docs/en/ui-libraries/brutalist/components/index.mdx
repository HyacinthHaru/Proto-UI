# Brutalist Components

All components inherit their Base family semantics and replace only the visual and state-feedback layer.

## Controls

- [Switch](./switch/) — mechanical actuator with direction-aware press feedback.
- Button — square poster action with lift and hard press.
- Toggle — persistent selection with geometry and fill as redundant signals.

## Composition

- Tabs — hard-edged list and selected trigger.
- Select — industrial trigger and portaled listbox.
- Dropdown Menu — poster-style trigger and menu surface.

## Overlays

- [Dialog](./dialog/) — bordered panel with industrial opener and dismiss controls.
- Hover Card — hard-shadow contextual surface.
