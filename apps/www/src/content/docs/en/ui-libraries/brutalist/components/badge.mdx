Brutalist Badge is the compact status-label projection of Base Badge.

## Contract

- Square geometry, `2px` ink border, and a small hard shadow.
- Bold mono uppercase text on Yandu Canary.
- Flat color only; no pill radius, gradients, glass, or glow.
- Explicit anatomy composition works without a component preset.

Use it for unread counts, participant roles, environment labels, and delivery status. Do not use Badge as an interactive control; compose Button or Toggle when activation is required.
