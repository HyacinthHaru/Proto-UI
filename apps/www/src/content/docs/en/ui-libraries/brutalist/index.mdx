Brutalist is a contributor-authored Neo-Brutalist style family for Proto UI. It is inspired by the broader Neo-Brutalist visual language—square geometry, strong borders, flat fills, hard offset shadows, abrupt movement, and high-contrast typography—but it is not a compatibility layer for a named third-party component system.

This foundation slice includes the shared visual grammar, light/dark theme variables, CLI style preset support, and the Button projection as the reference family. Additional families are introduced through separate focused PRs.

## Status

- Provenance: contributor-authored Proto UI style family, with general Neo-Brutalist visual references only.
- Semantics: Button inherits Base Button behavior; this slice adds only visual projection.
- Package surface: `@proto.ui/prototypes-brutalist` and `@proto.ui/prototypes-brutalist/button`.
- Maintenance: the contributor maintains the initial split sequence; release inclusion and long-term ownership remain subject to Proto UI governance.
