Brutalist Card is the seven-part Base Card anatomy rendered as a square paper panel with an ink frame and hard offset shadow.

## Contract

- Root owns only the visual surface; Base retains `role="group"` and slot anatomy.
- Header, Title, Description, Action, Content, and Footer remain explicitly composable.
- Header/Footer rules create strong hierarchy without hiding content behind decorative wrappers.
- No radius, gradient, glass, blur glow, or soft elevation.

Use Card for ChatUI sidebars, conversation panels, composer shells, dashboards, settings, and billing surfaces. A Card is a container, not a dialog or interactive control.
