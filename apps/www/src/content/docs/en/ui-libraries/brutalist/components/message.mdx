Brutalist Message renders a single chat message with direction-aware alignment and color.

- **Incoming** (default): left-aligned paper surface with ink border and hard shadow.
- **Outgoing**: right-aligned Yandu Canary surface.
- Mono text, square corners, no radius or gradient.

Use it inside a conversation panel composed with ScrollArea, Card, and Avatar.
