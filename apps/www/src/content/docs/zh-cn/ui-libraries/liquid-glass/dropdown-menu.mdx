## 分组动作组成（草稿）

Group 与 Label 建立实时辅助技术命名关系；Separator 和 Shortcut 是真实的被动部件。Shortcut 只显示提示，不注册全局快捷键。装饰部件不进入动作集合，也不增加 press owner。示例使用160px菜单、账户与资源分组和禁用的 API 动作。Invite users 的真实子菜单属于随后单独实现的协议片，不用演示盒子模拟。Checkbox/Radio变体及完整native/GPUI、Compiler、打包、视觉和独立验收仍未完成。

## 显式 Trigger 材质（草稿）

Trigger 现在声明共享 `liquid-glass` 意图，借用已有 Dropdown pressed 状态选择 rest/pressed deformation；圆角 geometry 与完整不透明 fallback 来自最终 style。Hover、focus-visible、disabled 和菜单激活仍由 Base 管理。Content 保留已有的 open 状态材质意图；此改动不新增 command owner，也不是仅存在于 demo 的效果。

现有共享 Web material provider 仅在应用内 Canvas source、geometry 与 preferences 获得准入时实现该意图。缺少能力、对比度不安全或 source 不可用时保留不透明 fallback；Trigger 可增强也不代表 portal 菜单必然有合法 source。这不是 native blur，也不声明 Apple-native parity。源码配方与隔离意图测试只属于实现证据：绑定新源码的 WC/React/Vue/Vue 2 明暗主题截图、真实交互绘制、GPUI 与独立视觉验收仍待完成。

公开预览同时提供独立 owner 的禁用 Trigger；通过真实 authored disabled prop 验证禁用行为，不使用测试专属 DOM 改写。
