在 default 尺寸下，两种 variant 使用固定上游尺寸：4px 12px 内边距、14px 字号、20px 行高、1px 边框与 4px 圆角。修改根字号不会放大这些像素值；这不代表浏览器缩放或原生目标已经验收。

## API

- variant: default / primary
- size: default / large / small / mini，默认 default
- 各尺寸保留 20px 行高与 1px 边框。large：11px 19px 内边距、17.5px 字号、6px 圆角（单行高 44px）；small：2px 10px、11.9px、3px（26px）；mini：0px 6px、10.5px、3px（22px）。
- disabled: boolean, default false
- 激活、焦点、键盘与禁用逻辑继承 Base Button，视觉层没有第二个状态拥有者。
