当前页面展示 Proto UI 中 `shadcn` 风格的 `toggle` 条目。尺寸、间距、圆角、outline 阴影与 active/hover 配方对照固定 [New York 02cad611](https://github.com/shadcn-ui/ui/blob/02cad61166c4c20edbc8a3f71bd720eed4c1f49b/apps/v4/registry/new-york-v4/ui/toggle.tsx)：default/sm/lg 高度为 36/32/40px（16px 根字号），active 使用 accent 与 accent-foreground；default 非 active hover 使用 muted 与 muted-foreground，outline hover 使用 accent。

Toggle 的 active、disabled、键盘与 a11y 仍由 Base 所有。`asChild` 有意不提供；原生属性/pressed API 别名、invalid 与任意嵌套 SVG 样式仍属兼容性差异。本页和源码测试不等于四 runtime、双主题的原生像素验收。
