本页面展示 Proto UI 当前的 Shadcn 风格 Base Input 投射。兼容比较基线为 [`shadcn-ui/ui` revision `f31ed81983653919dd4fe77aee4b4859f610f1dc`](https://github.com/shadcn-ui/ui/blob/f31ed81983653919dd4fe77aee4b4859f610f1dc/apps/v4/registry/new-york-v4/ui/input.tsx) 的 v4 new-york Input。这是 Proto UI 维护的非官方实现，不代表上游包或官方背书。

单行文本值、controlled/uncontrolled 行为、归一化编辑与 IME 事件、native 文本属性、textbox 命名和描述、disabled/read-only 状态以及 focus/blur 均由 Base Input 所有。Shadcn 层消费这套协议，只增加有界的 field surface、focus-visible ring、disabled 呈现和 dark-scheme 底色。最终仍只有一个 host-owned `input[type="text"]`。

这是经过验证的视觉子集，不宣称与上游完全一致。本投射通过受限的静态 token `selection:bg-primary selection:text-primary-foreground` 与上游保持文本选中色一致；其他样式变体（如 `placeholder:*`、响应式 `md:*`）仍不支持。上游没有自定义文本光标或插入光标颜色，因此此处也仍采用浏览器原生行为。Base Input 没有 invalid state；本投射也不公开任意 `type`、调用者 `className` 或 `data-slot`。它不增加 form/validation workflow、selection API 或第二个编辑器。
