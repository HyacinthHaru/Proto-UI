## Trigger 外观

默认 `appearance="flat"` 保留上方示例的5px圆角、2px黑框、main fill及配对ink。`appearance="elevated"` 仍是显式Proto UI扩展：静止态向右/下4px硬影，hover/press沿同方向移动4px并去除硬影。

`appearance="ghost"` 是另一项显式Proto UI扩展。静止边框与填色透明，使用随主题变化的前景且无硬影；hover/press使用中性表面，不移动，明暗主题均保留清晰的硬键盘焦点ring。main fill的黑色ink不会进入深色透明外观。

`appearance` 设置在 `brutalist-select-trigger`，不设在Root或Content；缺省或移除时即使在交互中也恢复 `flat`。size、chevron、Base选择、键盘导航、disabled与扁平Content不变。表单字段保留默认，consumer通过公共输入选择外观，不用页面CSS覆盖家族paint。
