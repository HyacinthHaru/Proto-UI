# Brutalist 组件

所有组件继承 Base 语义，仅替换视觉与状态反馈层。

## 控件

- [Switch](./switch/)：带方向感按压反馈的机械执行件。
- Button：方形海报动作控件。
- Toggle：用位置/填充冗余表达持久选中。

## 组合与浮层

- Tabs、Select、Dropdown Menu：硬边列表、触发器与 portaled 表面。
- [Dialog](./dialog/)：工业风面板、触发器与关闭控件。
- Hover Card：硬阴影上下文表面。
