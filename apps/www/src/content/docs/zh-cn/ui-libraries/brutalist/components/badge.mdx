Brutalist Badge 是 Base Badge 的紧凑状态标签投影。

## 契约

- 方角、`2px` ink 边框与小型硬阴影。
- Yandu 金丝雀黄表面上的粗体 mono 大写文本。
- 只用平涂色；禁止 pill 圆角、渐变、玻璃和柔光。
- 显式 anatomy composition 不依赖 component preset。

用于未读数量、参与者角色、环境标签和投递状态。Badge 不是交互控件；需要激活行为时应组合 Button 或 Toggle。
