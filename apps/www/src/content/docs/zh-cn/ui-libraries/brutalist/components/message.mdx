Brutalist Message 渲染单条聊天消息，按方向自动对齐和配色。

- **Incoming**（默认）：左对齐 paper 表面，ink 边框与硬阴影。
- **Outgoing**：右对齐 Yandu 金丝雀黄表面。
- Mono 文本、方角、无圆角或渐变。

在由 ScrollArea、Card 和 Avatar 组成的会话面板中使用。
