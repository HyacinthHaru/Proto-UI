Base Tooltip 现在持有 controlled/uncontrolled open state、可取消 open/close delay、disabled handling、Trigger pointer/focus intent、Content hover bridge、稳定的 `role="tooltip"`/`aria-describedby` linkage 与 Escape dismissal。Content 消费 non-modal Overlay 与 Transition，完成 fixed、Trigger-anchored portal positioning 和 presence。

显式 Portal part 仍是 logical anatomy carrier；renderer portaling 由 Content 持有。Arrow 仍是 visual-only slotted carrier，不持有 shape、geometry、side、collision 或 positioning behavior。Brutalist 继承 Base protocol，只为 Content 与 Arrow 增加 feedback style。Hover 或 focus Preview Trigger 即可打开 Tooltip。Tooltip 只补充 accessible name，不能替代它。
