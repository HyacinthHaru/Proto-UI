Brutalist 是 Proto UI 的贡献者原创 Neo-Brutalist 风格原型库。它参考的是广义 Neo-Brutalist 视觉语言：方角几何、强边框、平涂填色、硬偏移阴影、直接的运动方式和高对比排版；它不是对任何特定第三方组件系统的兼容层。

本基础切片只包含共享视觉语法、Light/Dark 主题变量、CLI style preset 支持，以及作为参考实现的 Button projection。其他 family 将通过独立小 PR 引入。

## 状态

- 来源：贡献者原创 Proto UI style family，仅使用一般 Neo-Brutalist 视觉参考。
- 语义：Button 继承 Base Button 行为；本切片只做视觉投影。
- 包入口：`@proto.ui/prototypes-brutalist` 与 `@proto.ui/prototypes-brutalist/button`。
- 维护：贡献者负责初始拆分序列；是否进入 release 及长期所有权由 Proto UI governance 决定。
