Brutalist 是 Proto UI 的贡献者原创 Neo-Brutalist 风格原型库。它参考的是广义 Neo-Brutalist 视觉语言：方角几何、强边框、平涂填色、硬偏移阴影、直接的运动方式和高对比排版；它不是对任何特定第三方组件系统的兼容层。

本聚焦切片保留共享视觉语法、Light/Dark 主题变量、CLI style preset 和参考 Button projection，并新增基于 Base anatomy 的 Scroll Area 视觉 shell。package 在 rc.7 仍为私有；行为扩展保留在独立后续 PR。

## 状态

- 发布状态：私有 workspace package（`0.0.0`），不改写已发布的 rc.6 evidence，也不提供公开 `proto-ui add` 条目。
- 来源：贡献者原创 Proto UI style family，仅使用一般 Neo-Brutalist 视觉参考。
- 语义：Button 继承 Base Button 行为；Scroll Area 在本切片中保留 Base anatomy，只增加视觉 shell。
- 包入口：私有 workspace source entries `@proto.ui/prototypes-brutalist`、`/button` 与 `/scroll-area`。
- 维护：贡献者负责初始拆分序列；是否进入 release 及长期所有权由 Proto UI governance 决定。
