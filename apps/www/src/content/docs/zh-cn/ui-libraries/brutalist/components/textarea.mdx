Brutalist Textarea 保留 Base 的 multiline value、change、disabled、focus 与 rows 语义，并增加方形 paper 编辑面与硬阴影。

标签与错误应组合 Field；提交生命周期和操作区应组合 Composer。Textarea 不拥有这些契约。

- Mono 文本、垂直 resize、明确的最小高度。
- 共享 Brutalist focus-visible 与 disabled feedback。
- 禁止圆角、渐变、玻璃和柔和 inset glow。
