Brutalist Composer 是消息输入行组件，包含输入框和发送按钮。

- **Root**：paper 表面的行容器，硬阴影与 ink 边框
- **Input**：canvas 文本输入区，方形边框
- **Actions**：操作容器
- **SendButton**：canary 方形按钮，按下效果

所有部件共享 `disabled` 状态。禁用 root 会传播到子组件。
