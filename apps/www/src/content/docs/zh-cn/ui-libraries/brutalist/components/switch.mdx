# Switch

外壳固定，方形 thumb 是执行件。

- Off：paper 轨道、ink thumb。
- On：天空蓝轨道、金丝雀黄 thumb；位置仍是 checked 主信号。
- Pressed：轨道切换为珊瑚红并移除硬阴影，释放后回弹。
- Focus：硬轮廓；Disabled：降低强调但保留结构。
