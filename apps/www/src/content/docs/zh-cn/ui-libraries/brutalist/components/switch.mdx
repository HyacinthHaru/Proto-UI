# Switch

外壳固定，方形 thumb 是执行件。

- Off：paper 轨道、ink thumb。
- On：电蓝轨道、酸黄 thumb；位置仍是 checked 主信号。
- Pressed：thumb 向待切换方向推进 `1px` 并横向压缩，释放后回弹。
- Focus：硬轮廓；Disabled：降低强调但保留结构。
