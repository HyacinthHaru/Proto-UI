Brutalist Card 把 Base Card 的七个 anatomy parts 投影为方形 paper 面板、ink 边框和偏移硬阴影。

## 契约

- Root 只拥有视觉表面；Base 保留 `role="group"` 与 slot anatomy。
- Header、Title、Description、Action、Content 和 Footer 保持显式组合。
- Header/Footer 分隔线建立强层级，不用装饰 wrapper 隐藏内容。
- 禁止圆角、渐变、玻璃、柔光与软 elevation。

用于 ChatUI sidebar、conversation panel、composer shell、dashboard、settings 和 billing surface。Card 是容器，不是 dialog 或交互控件。
