# Dialog

面板保持 Base Dialog 语义和命令连接，并使用工业海报式处理。

- 触发器使用电蓝色块与硬阴影。
- 右上角 X 是独立酸黄色方形控件，不是无边框图标。
- Hover 变警示红并增加硬阴影；Pressed 双轴推进 `1px` 并移除阴影。
- footer dismiss 动作保留明确关闭语义，不伪装成普通文本链接。
- 保留硬轮廓 Focus 和可访问名称 `Close`。
