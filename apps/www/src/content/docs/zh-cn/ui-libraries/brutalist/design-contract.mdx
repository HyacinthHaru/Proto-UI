# Brutalist 设计合约

本文档投影 draft 状态的 `P-BRUTALIST-*` 实体。语义、键盘、ARIA 和命令连接继续以 Base 合约为准。

## 几何

控件与表面使用方角；紧凑 chip/badge 可使用 `2px` 小圆角。边框固定为 `2px` 实线 ink 色。

## 深度与运动

| 状态 | 位移         | 硬阴影    |
| ---- | ------------ | --------- |
| 默认 | 无           | `3px 3px` |
| 悬停 | `-1px, -1px` | `4px 4px` |
| 按下 | `1px, 1px`   | 无        |

有活动部件的控件可固定外壳、只移动执行件。Switch 因此在按下时推进并横向压缩 thumb。

## 配色

基础为 paper/ink；Yandu 鲜明柔和调色板承担语义：金丝雀黄用于明确动作、薄荷绿用于确认、薰衣草紫用于 focus/批注、珊瑚红用于警示与按压、天空蓝用于发现和选中轨道。只用平涂色块，禁止渐变、玻璃和柔光。位置、标签和几何始终是主要状态信号。

## 无障碍

Focus 使用有偏移的硬轮廓。Disabled 保留边框与结构。交互目标保留可访问名称和 Base 键盘行为。Portal 浮层继承页面主题变量。
