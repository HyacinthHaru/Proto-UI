Shadcn Dialog 家族提供构建模态对话框的样式化部件。

- **shadcn-dialog-root**：持有 `open` 状态，并向所有子部件提供上下文。
- **shadcn-dialog-trigger**：无样式的语义 trigger；需要按钮外观时，在其中显式嵌套 Button。
- **shadcn-dialog-mask**：渲染背景遮罩层，跟随 open 状态进入/离开过渡。
- **shadcn-dialog-content**：内容容器，负责焦点陷阱、浮层关闭策略（ESC、外部点击）以及进入/离开过渡；生成的 convenience facade 会追加一个可替换的默认 CloseIcon。
- **shadcn-dialog-content-raw**：不执行 preset 物化的 generated raw facade。
- **shadcn-dialog-header**：可选的纯布局分组，用于容纳标题和描述。
- **shadcn-dialog-footer**：可选的纯布局 action 分组，不定义 Confirm、Cancel 或 Save 语义。
- **shadcn-dialog-title**：语义标题，自动通过 `aria-labelledby` 与 content 关联。
- **shadcn-dialog-description**：语义描述，自动通过 `aria-describedby` 与 content 关联。
- **shadcn-dialog-close**：无样式的语义关闭边界；需要按钮外观时，在其中显式嵌套 Button。
- **shadcn-dialog-close-icon**：Content preset 采用的、带 accessible name 的 X 关闭面。

向 `shadcn-dialog-content` 传入 `alert` 可将其转换为 alert dialog：禁用外部点击关闭，同时保留 ESC 关闭行为。

生成的 Content preset 区分三种状态：未覆盖时物化 CloseIcon；直接提供 CloseIcon 子节点（或 React `close` prop / Vue `#close` slot）时替换默认部分；React `close={null}`、空 Vue `#close` slot 或 Web Component `data-pui-no-default-close` 会明确省略默认部分。不希望存在 preset 行为时，可以直接使用 `ShadcnDialogContentRaw`。

Preset recipe 在原型库的 `packages/prototypes/shadcn/src/component-presets.ts` 中维护，只声明组件/part identity 与替换策略，不包含视觉 token。CLI 消费受检查的生成投影，并负责各宿主的具体物化。

Dialog 不预设 Confirm 或 Save 行为。需要先校验或持久化时，应保留普通 Button，并在操作成功后调用 `dialogRef.current?.getExposes().close('save')`。adapter ref 返回的 expose method 已经自动进入正确的 callback scope，调用者不需要手工处理内部作用域。
