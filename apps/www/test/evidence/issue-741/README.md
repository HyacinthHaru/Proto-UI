# Shadcn Input selection evidence

These captures show the actual Shadcn Input preview at candidate `d0e21bb9276892fb3ae714edb521eede3f5f60de`, rendered by the repository browser harness in headless Chrome on 2026-09-27 (Asia/Shanghai). The browser test selected the text in the real `input[type="text"]` inside the Web Components projection and recorded the light and dark presentation.

- `selection-light-wc.png`: Web Components preview with the selected text in the light scheme.
- `selection-dark-wc.png`: Web Components preview with the selected text in the dark scheme.

The screenshots are generated by `apps/www/src/content/docs/zh-cn/demo-shadcn-input.browser.test.ts`; the test also probes computed selection colors in Web Components, React, Vue, and Vue 2. This evidence demonstrates only the named Shadcn Input presentation. It does not claim non-Web host support or complete upstream parity.

The comparison reference is shadcn-ui/ui v4 new-york Input at [`f31ed81983653919dd4fe77aee4b4859f610f1dc`](https://github.com/shadcn-ui/ui/blob/f31ed81983653919dd4fe77aee4b4859f610f1dc/apps/v4/registry/new-york-v4/ui/input.tsx), MIT-licensed. The projection uses the corresponding public style-token names as visual reference; no upstream implementation code or assets are copied.
