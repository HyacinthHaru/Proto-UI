# Production Search and the Chromium IME trust boundary

The [managed Linux job](https://github.com/HyacinthHaru/Proto-UI/actions/runs/42951861312/job/130319498622) ran the earlier exact source `5f2d845ce54666a167f06895033a616d8bfa3382`. The production build produced 673 pages and Pagefind indexed 647 pages. The original browser file reported 0/4. Brutalist reached real index assets and 97 Button results after an injected HEAD 503, then failed the separate runtime assertion. Shadcn failed its runtime assertion before the delayed retry completed.

Both production IME cases received trusted start, update and composing input events. The only compositionend had `isTrusted=false`. The unchanged original predicate failed before the result-navigation portion. The query was `Button` and the real result count had returned to 97. The published frame is the unedited original Shadcn failure capture. The [original hosted archive](https://github.com/HyacinthHaru/Proto-UI/actions/runs/42951861312/artifacts/13829486107) retains both cases and the other failures.

A separate local bare input on Chrome for Testing 156.0.8078.79, macOS arm64, received the same CDP insert, Shift+ArrowLeft twice, composition update, ArrowDown and native commit sequence. It had no Website code, and emitted one compositionend with `isTrusted=false`, with final Button and caret 6:6. The source of the matching Chromium version dispatches this event directly through the scoped event queue. [CDP insert path](https://github.com/chromium/chromium/blob/156.0.8078.79/content/browser/devtools/protocol/input_handler.cc#L1281-L1304) · [Blink compositionend dispatch](https://github.com/chromium/chromium/blob/156.0.8078.79/third_party/blink/renderer/core/editing/ime/input_method_controller.cc#L326-L340) · [Node trust-setting entry](https://github.com/chromium/chromium/blob/156.0.8078.79/third_party/blink/renderer/core/dom/node.cc#L3328-L3331)

The bare input establishes the same browser behavior without the Website on a second OS. A same-process hosted pair can further isolate the platform boundary. The original product predicate and deadlines remain intact, and the current Search head requires its own managed production evidence.
