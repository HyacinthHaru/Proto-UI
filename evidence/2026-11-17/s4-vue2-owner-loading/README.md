# S4 Vue 2 Base Accordion load boundary

Both native probes run the same full static Matrix HTML with the existing local diagnostic theme and virtual-list patches. Each retains all 1,268 previews, the 60-second readiness predicate and the 150-second outer bound. The archive binds the Vue 2 instrumentation and the two test-input overlays.

In the normal-dispatch probe, the Vue 2 wrapper and adapter return near 14.27 seconds. The native runtime import starts at 14.27 seconds. Chrome reports HTTP 200 and a loading-finished event for its actual runtime asset. The Base Accordion demo's six prototype imports finish near 49.66 seconds, and its renderer enters the runtime join. Neither completion of the runtime import nor return from the join is recorded before the outer timeout. The last original readiness sample identifies this empty Vue 2 owner.

The second probe adds an early call to the existing Vue 2 loader from DOMContentLoaded. The runtime then returns around 13.42 seconds. The same owner's prototype-loading start is recorded, but completion of those prototype imports is absent. The original 60-second readiness check fails before render and Dialog, and the post-verdict read reaches its own limit. This is an instrumented comparison with different observed failure boundaries. It does not establish a generally passing preload strategy or a network-duration estimate.
