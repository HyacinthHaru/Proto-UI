# S4 React entry transport and import completion

The unchanged bilingual S4 case ran against a detached d854cae checkout with the named phase and network diagnostic patch. It retained the complete matrix and original 150-second case deadline. Both cases timed out, with 18 unsupported owned-decoration page errors each and no console errors.

In both locales the browser recorded HTTP 200 and requestfinished for react.js, react-dom.js and react-dom_client.js. The Base Accordion host was still empty when its renderer reached loadReact. No resolve or reject callback for the three observed import promises and no root render request was streamed before the original deadline.

The network observations cover the three optimized entry URLs. They leave transitive module loading, evaluation and renderer scheduling open. No workaround or change to Shadow admission is included.
